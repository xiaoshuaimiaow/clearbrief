# ClearBrief 清晰启动

ClearBrief 是一个面向产品经理和项目负责人的项目启动与需求预评审工作台。它把模糊需求、会议纪要、聊天记录或文档片段整理成可讨论、可评审、可分工的项目材料。

## 在线体验

项目主页：https://xiaoshuaimiaow.github.io/clearbrief/

进入主页后可以体验完整流程：输入项目想法、追问补齐、生成 PRD、查看评审报告，并导出给不同角色使用的材料。

## 项目定位

很多项目不是从完整 PRD 开始，而是从一句模糊需求开始。真正影响推进效率的，往往不是没人写文档，而是目标用户、范围边界、权限规则、验收标准和上线风险没有在早期被问清楚。

ClearBrief 的重点不是自动写一篇更长的 PRD，而是把“需求澄清 -> 跨部门对齐 -> 竞品分析 -> 数据指标 -> PRD 生成 -> 需求评审”串成一条产品经理工作流。

## 核心功能

- 录入模糊需求、会议纪要、聊天记录或文档片段
- 识别项目类型、目标用户和当前信息缺口
- 按优先级生成追问问题，补齐目标、范围、指标、权限和兜底流程
- 生成包含跨部门对齐、竞品分析、数据指标和 SQL 口径的 PRD 草稿
- 输出需求评审报告，展示完整度评分和问题清单
- 按角色导出老板摘要、研发任务、设计 brief、运营材料和 kickoff 议程

## 体验路径

1. 打开项目主页。
2. 点击“进入在线体验”。
3. 在输入页选择一个案例，或输入自己的项目想法。
4. 点击“开始分析”，查看系统识别出的信息缺口。
5. 在追问页确认关键回答。
6. 生成完整 PRD，并查看竞品分析、跨部门对齐、数据指标和 SQL 示例。
7. 进入评审报告，再到工作台查看不同角色的材料。

## 文件说明

- `index.html`：项目介绍页
- `demo.html`：在线体验页
- `prd.html`：公开产品说明文档
- `PRD.md`：Markdown 版产品说明

## 当前版本

当前版本用于展示产品流程和交互闭环，覆盖从模糊需求输入到 PRD 生成、跨部门对齐、竞品分析、数据分析和评审导出的完整路径。

生产环境可以接入后端和大模型服务，并结合企业权限、调用成本、日志审计和人工复核机制，支持更真实的需求预评审场景。
