# ClearBrief 清晰启动

ClearBrief 是一个项目启动与需求评审工作台，面向产品经理、项目负责人和跨职能协作团队。它帮助用户把模糊需求、会议纪要、聊天记录或文档片段整理成可讨论、可评审、可分工的项目启动材料。

## 项目定位

很多项目并不是从一份完整 PRD 开始，而是从一句模糊需求开始，例如“公司文档太散，想做一个知识库”。真正影响推进效率的，往往不是没有文档，而是目标用户、范围边界、权限规则、验收标准和上线风险没有在早期被问清楚。

ClearBrief 的重点不是自动写一篇 PRD，而是把“需求澄清 -> 启动文档 -> 评审报告 -> 跨部门导出”串成一条工作流。

## 核心功能

- 录入模糊需求、会议纪要、聊天记录或文档片段
- 识别项目类型、目标用户和当前信息缺口
- 按优先级生成追问问题，补齐目标、范围、指标、权限和兜底流程
- 生成项目启动文档，包括背景、MVP 范围、风险和验收标准
- 输出需求评审报告，展示完整度评分和问题清单
- 支持问题状态更新，评分会随处理进度变化
- 按角色导出老板摘要、研发任务、设计 brief、运营材料、Kickoff 议程和管理员配置清单

## Demo 场景

企业内部文档分散，新员工和运营同事经常找不到会员政策、项目资料和流程制度。团队希望启动一个内部知识库改版项目，提高信息查找效率，减少重复沟通。

## 推荐体验路径

1. 打开 `demo.html`。
2. 在输入页点击“开始分析”。
3. 在追问页选择任意一个问题并点击“确认回答”。
4. 生成启动文档，应用右侧建议。
5. 进入评审报告，模拟处理高优先级问题。
6. 在导出中心生成不同角色的材料。
