# ClearBrief 清晰启动

ClearBrief 是一个面向产品经理和项目负责人的项目启动与需求评审工作台。它帮助用户从模糊需求、会议纪要、聊天记录或文档片段中提取关键信息，识别缺口，并生成可评审的项目启动材料。

## 在线页面

部署到 GitHub Pages 后：

- 项目介绍页：`/`
- 可点击 Demo：`/demo.html`
- 产品说明文档：`/prd.html`

## 项目背景

很多项目并不是从一份完整 PRD 开始，而是从一句模糊需求开始。产品经理需要在项目早期反复追问目标用户、业务目标、范围边界、权限规则、验收标准和上线风险，才能把想法转成可执行方案。

ClearBrief 的目标不是简单生成文档，而是把“需求澄清 -> 启动文档 -> 评审报告 -> 跨部门导出”串成一个完整工作流。

## 核心功能

- 模糊需求录入
- 智能识别项目类型和信息缺口
- 追问补齐目标、范围、指标、权限和兜底流程
- 生成项目启动文档
- 输出需求评审报告
- 支持问题状态更新和评分变化
- 按角色导出老板摘要、研发任务、设计 brief、运营材料和 kickoff 议程

## Demo 场景

企业内部文档分散，新员工和运营同事经常找不到会员政策、项目资料和流程制度。团队希望启动一个内部知识库改版项目，提高信息查找效率，减少重复沟通。

## 适用场景

- 新项目启动前的信息补齐
- 跨部门需求评审
- 企业内部工具或知识管理项目
- 项目材料按角色拆分导出
- 产品、研发、设计、运营之间的早期对齐
