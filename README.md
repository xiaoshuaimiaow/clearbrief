# ClearBrief 清晰启动

ClearBrief 是一个面向 0-3 年产品经理和项目 owner 的需求评审前预检工具。它帮助用户把模糊需求、会议纪要、聊天记录或文档片段整理成可讨论、可评审、可分工的项目启动材料。

在线体验：https://xiaoshuaimiaow.github.io/clearbrief/

## 项目定位

很多项目不是从完整 PRD 开始，而是从一句模糊想法开始。真正影响推进效率的，往往不是没人写文档，而是目标用户、范围边界、权限规则、验收标准、数据指标和上线风险没有在早期被问清楚。

ClearBrief 的重点不是自动写一篇更长的 PRD，而是把“需求澄清 -> PRD 生成 -> 需求评审 -> 研发反馈 -> 角色化导出”串成一条产品经理工作流。它更像评审前预检助手：先发现问题，再组织材料，最后帮助团队更高效地进入讨论。

## 核心功能

- 输入模糊需求、会议纪要、聊天记录或文档片段
- 识别项目类型、目标用户和当前信息缺口
- 按优先级生成追问问题，补齐目标、范围、权限、指标和兜底流程
- 生成包含跨部门对齐、竞品分析、数据指标、SQL 口径和验收标准的 PRD 草稿
- 支持会前材料检查、角色意见确认、评审待办处理和研发反馈回写
- 导出 PRD、评审会议纪要、老板摘要、研发任务清单、设计 Brief 和数据分析口径

## 页面说明

- `index.html`：产品经理作品集案例首页
- `demo.html`：可点击在线 Demo
- `prd.html`：公开产品说明文档
- `PRD.md`：Markdown 版产品说明

## 体验路径

1. 打开项目主页。
2. 点击“体验可点击 Demo”。
3. 选择一个业务案例，或输入自己的项目想法。
4. 点击“开始分析”，查看系统识别出的信息缺口。
5. 在需求澄清页确认关键回答。
6. 生成完整 PRD，并查看竞品分析、跨部门对齐、数据指标和 SQL 示例。
7. 进入需求评审，处理会前材料、角色意见、评审待办和研发反馈。
8. 在工作台导出不同角色可用的材料。

## 产品亮点

- 不是直接生成文档，而是先追问补齐关键信息。
- 不只展示理想流程，也覆盖材料缺口、阻塞项、研发反馈和会后动作。
- 评审模块更贴近真实工作：关注是否能进入下一阶段，而不是单纯看分数。
- 输出材料可编辑，避免完全依赖 AI 一次性生成。

## 使用边界

当前版本是前端可点击原型，模拟 AI 分析流程。真实接入 AI 时，需要通过后端接口调用大模型，避免 API Key 暴露，并处理企业权限、敏感信息、调用成本、失败兜底、日志审计和人工复核。

ClearBrief 不替代业务决策、技术评估、法务审核或财务审批。它的价值是帮助产品经理在评审前更早发现缺口。

## 后续可扩展

- 接入真实 AI 后端，支持实时生成追问和 PRD。
- 接入企业文档、会议纪要或协作工具，减少手动输入成本。
- 增加历史项目管理、评审记录沉淀和团队权限控制。
- 做 2-3 次轻量用户试用，验证追问是否有帮助、评审模块是否容易理解、导出材料是否可直接使用。
